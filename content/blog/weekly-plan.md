## 从每周两次全身训练开始

新手可以在每次训练里覆盖主要肌群，反复练习少量动作。胸、背、肩、腿的专题页是动作参考，初学时无需按四天分部位把日程填满。每周两次能坚持，再考虑第三次。

WHO建议成年人每周至少两天做主要肌群的力量训练，并累计150—300分钟中等强度有氧活动，或等量的高强度活动。初学者可从较少的量起步，逐步靠近指南。

## 一周如何排

以下全部属于**本站新手实践示例**：

| 日期 | 安排 |
| --- | --- |
| 周一 | 全身A：椅子坐站、器械推胸、胸托划船、扶椅提踵 |
| 周二 | 快走15—25分钟 |
| 周三 | 休息，日常活动间隙起身走动 |
| 周四 | 全身B：椅子坐站、墙壁俯卧撑、高位下拉、站姿向后抬腿 |
| 周五 | 快走15—25分钟 |
| 周六 | 轻松骑车或快走20—30分钟 |
| 周日 | 休息，整理训练记录 |

站姿向后抬腿时扶住稳固椅背，躯干不晃，腿轻轻向后伸，再控制放回，避免靠挺腰抬高。它是温和的起步动作，熟悉之后可请教练教髋铰链等进阶练习。

每个力量动作先做1—2组，通常每组8—12次；体力较弱时，坐站和提踵可从5次开始。组间约休息1—2分钟，较吃力时多休息。动作开始变形前结束，保留余力。

## 第三次怎么加，有氧怎么补

连续几周恢复良好、时间也充裕，可以改成周一A、周三B、周五A，下一周B／A／B，让力量训练之间有休息日。第三次加入时，先维持每次组数，不同时大幅加重。

表中有氧只是起步量，尚未达到每周150分钟。可先增加每次5分钟，再把通勤快走或午间步行算进去，逐渐接近指南。中等强度可用谈话测试判断：能说话，但唱歌困难。力量训练的组间休息不算作有氧分钟。

## 忙碌和不舒服时怎么调整

一周只剩两天，就保留两次全身训练；只有一次，也照常完成能做的部分，下周恢复。某个动作疼痛时停止，选不痛的替代或寻求指导。明显疲劳、睡眠不足、酸痛影响动作时，减少组数或改成轻松走路。

这份计划的作用是帮助开始。四周后先问自己：到场是否稳定、动作是否更熟、是否恢复得过来，再决定加量。
